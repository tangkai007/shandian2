### 1.1 红线与约束（设计硬约束，来自 Issue「明确不做」+ 设计 §4.6）

| 编号 | 约束 | 设计落点 |
| --- | --- | --- |
| **R-1** | 禁止「替换后照说」；违禁词只能「检测 + 改写建议 + 发布拦截」 | 合规中心 DES-C05；**改写建议不得有「一键播报」** |
| **R-2** | 禁止「伪装真人」；AI 合成必须明示 | Overlay 常驻 DES-O01；**明示标识不可关闭** |

| **R-5** | 不复制卡密授权 / 破解 / 受保护皮肤 | 无登录卡密 UI；视觉为原创 |

### 3.2 DES-C00 顶栏（全局）

| 元素 | 内容 | 状态 |
| --- | --- | --- |
| 应用名 | 「AI 直播助播」+ 版本号 | 常态 |
| **AI 明示徽标** | `[AI]` 徽标（`color/ai/badge` 渐变），悬停 tooltip：「本工具使用 AI 合成语音播报。合成语音在直播画面常驻明示。」 | **常驻、不可移除**（R-2） |
| 平台状态 pill | ● 已连接（绿）/ ◌ 重连中 n 次·退避 8s（橙，含倒计时）/ ✕ 已断连（红）/ ○ 未启动（灰） | 见 DES-C04 |
| 运行时长 | 开播计时 `HH:MM:SS` | 未开播 → 「未开播」 |
| **一键停** | 红色实心按钮，文案「一键停」；悬停显示「立即停止播报与自动发送」 | 禁用（未开播时置灰） |

### 3.3 DES-C01 概览（Dashboard）

四区布局（Standard 断点 2×2，Wide 断点 4 列）：

1. **连接卡**：平台、房间号/URL（脱敏显示）、连接状态、重连次数、最后事件时间。
   - 空态：`○ 未开播` + 主按钮「开始播控」。
   - 重连态：橙色 banner「连接已断开，正在第 3 次重连（退避 8s）」+ 「立即重连」/「停止」。
2. **运行卡**：当前角色（主播/助播/插播 + 音色）、输出通道（TTS / 预录音频）、音量、轮换倒计时、运行时长。
   - 降级态：通道显示「预录音频（TTS 不可用）」+ ⓘ。
3. **实时事件流**：滚动列表，每行 `时间 · 类型图标 · 用户 · 内容 → 命中规则/应答`。
   - 类型：弹幕 / 进入 / 关注 / 点赞 / 礼物 / 主播语音 / 系统。
   - 空态：`暂无事件，开播后弹幕会出现在这里`。
   - 冻结/暂停滚动开关；点击行 → 侧抽屉显示详情（含是否被拦截）。
4. **合规摘要卡**（`color/compliance/accent` 左边框）：今日拦截 N 条 / 禁说词命中 M 条；最近 3 条拦截（命中词高亮）；「查看合规中心 →」。
   - 全 0 时：`✓ 今日无违规拦截`。

快捷操作条：[开始播控] [测试播报] [暂停应答] [打开 Overlay 预览]。

### 3.4 DES-C02 规则管理

三栏：**规则文件树 | 规则表 | 规则编辑器/预览**。

- **文件树**：`rules/*.txt`，分组显示：匹配类（全匹配关键词 / 单匹配关键词 / 模糊）、事件类（感谢关注/点赞/礼物/欢迎新人）、定时类（随机插话报时）、ASR 类（回答主播）、弹窗类（关键词弹窗）。每项显示规则条数 + 校验告警数角标。
- **规则表列**：模式（FULL / SINGLE / FUZZY 标签）、关键词组、回复摘要、状态（✓ 有效 / ⚠ 告警 / ✕ 无效）、行号。
  - 模式标签色：FULL=蓝、SINGLE=青、FUZZY=紫。
  - 三态：loading（骨架行）/ empty（`该文件暂无规则` + 「新增规则」）/ 列表。
- **编辑器**（沿用原件 txt 语义，零迁移）：
  - 原文编辑区（`font/family/mono`）：`关键词组=回复`；`【a#b#c】` 随机取一；`{变量}` 高亮。
  - 辅助面板：**变量插入**（`{用户名称}{现在时间}{在线人数}{礼物名称}{再过10分钟}` 五个 chips，点击插入）；**随机组**按钮插入 `【】`；**商品弹窗**三段式模板 `关键词=商品号=文案`。
  - **实时校验反馈**（对应设计 §3.2 / RISK-3）：
    - 无 `=` 的行 → ⚠ 黄条「第 N 行无 `=`，将按注释忽略」+ 「查看」定位（**不静默丢弃**）。
    - 未知变量 → ⚠「未知变量 `{xxx}`，运行时保留原文并告警」（DECISION-4）。
    - 三段落规格不符 → ✕「商品弹窗需 `关键词=商品号=文案` 三段」。
    - 重复关键词组 → ⚠「与第 M 行关键词重复，按行序优先」。
  - 底部：[保存] [另存为] [还原] ；未保存时标题加 ● 脏标记。
- **保存失败态**：✕ toast「保存失败：文件被占用 / 无写入权限」+ 重试。

### 3.5 DES-C03 角色管理

三张角色卡（主播 / 助播 / 插播），横向排列（Compact 断点纵向堆叠）：

| 字段 | 说明 |
| --- | --- |
| 启用 | 开关 |
| 音色 | 下拉（来自 `voices/`；空则「未加载音色，请侧载」+ 跳转 DES-N） |
| 绑定规则子集 | 多选（规则文件 / 分组） |
| 轮换间隔 | 60s / 120s / 自定义（对应原件 `更换主播模型1..4`） |
| 试听 | ▶ 按钮（TTS 或预录） |

- 下方**轮换时间轴**：横向时间轴预览轮换顺序与切换点。
- **合规提示条**（R-2/R-3 相关）：`轮换仅用于听感自然，不用于规避平台身份识别`（只读说明，非开关）。
- 状态：某角色音色缺失 → 卡片黄色边框 + 「缺音色」标签；全部缺失 → 顶部 banner 引导侧载。

### 3.6 DES-C04 状态与健康

分组列表（每行：图标 + 名称 + 状态 + 详情 + 操作）：

| 分组 | 行项 | 状态取值 |
| --- | --- | --- |
| **平台** | 抖音连接 | 未启动 / 已连接 / 重连中（第 n 次，退避 xx s）/ 已断连 / 只读采集（方案 C 过渡） |
| **应答通道** | TTS sidecar `:12880` | 健康 / 不可用（→ 降级预录音频）/ 启动中 |
| | ASR sidecar `:9880` | 健康 / 不可用（→ ASR 功能停用）/ 启动中 |
| **资源** | 外挂目录 Manifest | 校验通过 / 缺失项 / 版本不匹配 / sha256 不符 → 「前往侧载」 |
| **运行时** | 事件队列 / 去重表 / 冷却表 | 队列深度、表条目数 |
| **审计** | 落盘状态 | 正常 / 写入失败 |

- **降级 banner（顶部，橙色）**：`TTS 不可用，当前仅预录音频应答` + 「重试」/「侧载模型」。
- **断连 banner（红色）**：`平台连接已断开` + 重连倒计时 + 「一键停」。
- 所有状态变化写审计并推入事件流。

### 3.7 DES-C05 合规中心（红线落点）

三个分区：

1. **禁说词过滤**（范围内第 9 项，1:1：命中即不输出）
   - 词表编辑（`config/compliance/禁说词.txt`）+ 命中计数。
   - 说明：「命中即静默不输出，不替换、不改写」。
2. **违禁词检测与改写建议**（红线① 合规替代）
   - 违禁词库（`最/第一/唯一/绝对/顶级/国家级…`）——版本化，可查看来源。
   - 开关：`发布拦截`（**默认开，建议锁定**）；`改写建议引擎`：本地规则库（默认）/ LLM 增强（**默认关，显式开启**，DECISION-6）。
   - **拦截记录表**：`时间 | 来源（规则/商品/角色） | 原文 | 命中词(高亮) | 处理=已拦截 | 改写建议`。
   - **改写建议卡**：展示「不含违规主张」的改写文案 + [复制]。
     - ⚠ **无「一键播报 / 直接发送」按钮**（R-1 硬约束）；若未来要播报，必须经人工编辑后回填规则文件。
3. **红线边界说明**（只读信息块）
   - 「本工具不实现：① 违禁词同义替换后照说；② 无人直播伪装真人；③ 反检测/指纹伪装。」（对应 NG-1/NG-2/NG-5）

- 状态：无记录（`✓ 今日无违规拦截`）/ 有记录 / 词库加载失败（✕ + 重试）。

## 4. 界面 B — Overlay（直播画面叠加层）

**设计约束**（不指定框架）：透明背景 + 置顶 + 点击穿透 + 可拖动定位 + 多显示器 + 分辨率自适应。需在 1080p 横屏与竖屏（1080×1920）下均可用；遵守平台安全区（不遮挡平台自身 UI 关键区，见 §6.5）。

### 4.1 DES-O01 AI 明示标识（常驻，不可关闭）

| 属性 | 规格 |
| --- | --- |
| 形态 | 圆角 pill：`[AI] AI 合成语音`（视觉唯一使用 `color/ai/badge` 渐变，保证可识别） |
| 位置 | 默认右下角，距边缘 `space/4`；可配置为四角其一 |
| 尺寸 | 高 32px；字号 `font/size/caption`；内边距 12×8 |
| 透明度 | 默认 92%（可调 70–100%，**下限 70 保证可读**）；**不允许隐藏** |
| 常驻性 | 直播全时段可见；开播即出现，停播后消失 |
| tooltip/说明 | 「AI 合成语音明示标识（合规要求，不可关闭）」 |
| 反色适配 | 提供「浅底/深底」两套配色，按画面亮度切换；对比度 ≥ 4.5:1 |
| 状态 | 正常运行即显示；Overlay 未启用时，顶栏 DES-C00 徽标仍常驻（双重保障 AC-6） |

### 4.2 DES-O02 商品弹窗

| 属性 | 规格 |
| --- | --- |
| 触发 | ① 规则命中（`关键词=商品号=文案`，受控降级默认关）；② 手动触发（控制台/快捷键） |
| 内容 | 商品号徽标 + 商品文案 + 缩略图位（可选）+ **AI 明示标识同框** |
| 位置 | 默认画面左下角；可配置左右/上下；多弹窗以队列依次显示 |
| 时长 | 默认 8s，可在设置调整（3–20s） |
| 动效 | 进入 240ms 上滑+淡入；退出 160ms 淡出（`motion/overlay-popup`） |
| 队列 | 最多同时显示 1 条；超出进队列并显示 `+n` 计数 |
| 状态 | 正常 / 队列中 / 空（无商品则不显示）/ 降级禁用（自动触发关闭时手动仍可用，若总开关关闭则整体禁用并提示） |
| 关闭 | 手动弹窗可点 ✕；规则触发弹窗到时自动关闭 |

### 4.3 DES-O03 运行提示（仅操作端可见）

- 断连 / 降级 / 重连的**小 toast** 出现在 Overlay 内（仅本机操作端可见，不进直播流）：例如 `⚠ 平台断连，重连中（3）`。
- 设计约束：该提示**属于操作端覆盖层**，须与「会进入直播流的内容（AI 明示 / 商品弹窗）」区分——提供「仅本地预览 / 进入直播捕获」两种通道的**视觉标注**（角标 `本地` vs `直播`），由 @FrontendDev 按采集方式实现区分。
- 空态：无提示时不占位。

## 5. 界面 C — 侧载引导页

首启或资源缺失时进入（也可从控制台「侧载与资源」进入）。步骤条：`① 环境自检 → ② 资源清单 → ③ 侧载导入 → ④ 完成`。

### 5.1 DES-N01 环境自检（加载态）

- 逐项检测（骨架 + 进度）：`models/`、`voices/`、TTS 端口 12880、ASR 端口 9880、Chrome 路径（原件配置项，设计 §1.2）、写入权限。
- 检测中：骨架屏 + 单项 spinner。
- 结果：全部通过 → 自动跳到 ④；有缺失 → ②。

### 5.2 DES-N02 资源清单与 Manifest 校验

表格列：`资源 | 类型(TTS模型/ASR模型/音色) | Manifest 期望版本 | 当前版本 | 大小 | sha256 校验 | 状态`。

| 状态 | 展示 |
| --- | --- |
| ✓ 就绪 | 绿色 ✓ |
| ⚠ 缺失 | 「缺失」+ [导入] |
| ⚠ 版本不匹配 | 期望 vs 当前 + [更新] |
| ✕ 校验失败 | 「sha256 不符，文件可能损坏」+ [重新导入] |

- 底部：[全部导入]（选目录/压缩包）；[跳过，降级为仅预录音频]（次按钮）。
- 空态（资源齐全）：`✓ 所有外挂资源已就绪`。

### 5.3 DES-N03 侧载导入 + 降级确认

- 导入：选择本地目录 / `.zip` → 校验 sha256 → 版本比对 → 逐项进度 → 完成/失败。
  - 失败态：✕「校验失败：`models/tts/xxx.bin` sha256 不符」+ 重试 / 跳过该项。
  - 权限态：✕「目标目录不可写，请以管理员运行或更换目录」。
- **降级确认弹窗**（选择跳过时）：
  - 标题「未安装全部模型」
  - 正文：「当前将**仅使用预录音频**应答；TTS / ASR 功能不可用。稍后可在控制台『侧载与资源』补装。」
  - 主按钮「仍要跳过」（次色），次按钮「返回导入」。
  - 对应设计 §4.4 降级约定（AC-3）。

### 5.4 DES-N04 完成页

- `✓ 准备就绪` + 摘要（已就绪资源 / 降级项）+ [进入控制台]。
- 若存在降级项：顶部保留橙色提示条。

### 5.5 后续入口

控制台侧导航「侧载与资源」= 复用 DES-N02 的资源清单（可随时补装/校验/替换模型目录，对应 AC-4「模型目录可独立替换」）。

## 8. 关键用户流与交互规则

### 8.1 首次启动 → 侧载 → 开播

```
启动 → [检测外挂资源] ─齐全→ 概览(未开播)
                     └缺失→ DES-N01 自检 → DES-N02 清单 → 导入/跳过
                              └跳过→ 降级确认 → 仅预录音频
                     → 概览「开始播控」→ 顶栏状态 ● → Overlay 出现 AI 明示
```

### 8.2 弹幕 → 应答（含合规拦截）

```
弹幕事件 → 命中规则(FULL/SINGLE/FUZZY) → 去重/冷却判定 → 模板求值(随机/变量)
 → 合规模块：禁说词命中? ─是→ 静默不输出(记审计)
            违禁词命中?  ─是→ 拦截 + 生成改写建议(不可一键播报) → 合规中心记录
            通过 → 通道选择：TTS可用? 是→TTS；否→预录音频? 是→播放；否→静默(降级)
 → 事件流显示 + 审计落盘
```

交互规则：
- 命中即处理，实时写入事件流（`aria-live` 播报关键变更）。
- 任一环节失败不弹阻断式弹窗，只在事件流 + 状态页标记（不打断直播）。

### 8.3 断线 → 重连

```
连接断开 → 顶栏 pill ●→◌(重连中 n) + 红色 banner(倒计时) + 一键停可用
 → 指数退避重连 → 成功: pill ● + banner 消失 + 审计
                → 多次失败: pill ✕ 已断连 + 建议检查网络/账号 + 保留一键停
```

### 8.4 受控降级（自动发送）启用流

```
设置 → 自动发送开关(默认关) → 点击开 → 二级确认弹窗(风险+勾选+限频)
 → 确认 → 开关开 + 顶栏出现「自动发送已启用」警示 chip(可点击直达关闭) + 审计
```

### 8.5 交互规则汇总

| 规则 | 说明 |
| --- | --- |
| 打断 | 任何错误/降级都**不阻断直播**，仅在状态区/事件流呈现 |
| 危险操作 | 一键停 / 受控降级启用 / 清空日志 → 二次确认 |
| 保存 | 规则/设置保存失败必给可操作错误（重试/换目录），不静默 |
| 实时性 | 事件流、状态 pill、合规计数实时更新（≤1s 延迟） |
| 一致性 | 同一状态在顶栏、状态页、Overlay 提示三处表述一致 |

## 10. 设计说明（难以用图表达的规则）

1. **AI 明示是双保险**：Overlay 标识（直播流可见）+ 控制台徽标（操作端）同时存在；即便 Overlay 未开，控制台仍明示（AC-6 不因 Overlay 关闭而失守）。
2. **改写建议永不自动播报**：合规中心只有「复制」，没有「发送/播报」按钮；这是 R-1 的硬边界，实现时不得加。
3. **不做风控规避开关**：任何「隐身 / 防检测 / 指纹」相关开关一律不出现（NG-5）。
4. **自动发送的视觉警示**：一旦启用，顶栏常驻警示 chip，避免「开了忘记关」。
5. **降级即明示**：任何降级（TTS 不可用、平台只读采集）都在状态页 + 事件流 + 相关 banner 三处一致标注，不静默。
6. **文案规则**：所有涉及 AI 的文案用「AI 合成语音 / 数字人」表述；**禁止**「我们是真人」「真人主播在播」等表述进入模板默认值（R-2、DECISION-5）。
7. **规则文件零迁移**：编辑器以原 txt 语义为唯一真相，UI 不做破坏性格式转换；解析容错（无 `=` 行）在 UI 可见。
